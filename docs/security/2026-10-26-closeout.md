## Corrections Found During Acceptance

- Printing silently failed when popups were blocked, omitted document language and immediately closed its print window. The replacement is an escaped, localized, accessible preview that stays available for printing/retry, with an actionable blocked-popup message. Preview creation does not force a native printer dialog. Actual PDF samples are generated from the app-created document, not a separately reconstructed document.
- An idle-triggered guide interrupted the initial reading/task after 2.2 seconds. It is now explicitly opt-in through Quick guide; the visible task-first flow remains the primary onboarding path.
- Global Enter handling duplicated native button activation, skipping guide steps or cancelling Back. Native activation now occurs once; arrow navigation is bounded, Tab stays inside the guide and closing restores the trigger.
- Firefox reported invalid font-table warnings from the Google-hosted Merriweather fallback. That request/fallback was removed; primary typefaces remain, with a system serif fallback.
- Test workers are explicitly limited to four to avoid unnecessary concurrent startup contention. Runtime-rejection assertions, the six-second fixture subprocess limit and 30-second file deadline are unchanged; a direct non-npm test invocation correctly fails its npm-environment precondition.
- A reusable `smoke:production` command now verifies an exact deployed revision and public security/routing/asset boundaries without exporting sensitive headers or bodies.
